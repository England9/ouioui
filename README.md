# Ginza Rooftop Honey Catch

A hyper-casual 15-second arcade playable ad for the **Ginza Honey Bee Project** — urban rooftop beekeeping in Tokyo’s Ginza district.

Catch cherry blossoms, tulip tree flowers, and horse chestnut nectar. Dodge rain, wind, and wasps. Built with Vite + TypeScript + Canvas.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

```bash
npm run build    # production build
npm run preview  # preview the build
```

## Play

- **Mobile:** swipe / drag left–right to move the honeycomb jar
- **Desktop:** arrow keys (or A/D), Enter/Space to start
- **Round length:** 15 seconds
- End screen shows which flower you caught most, with dessert + eco-project CTAs
